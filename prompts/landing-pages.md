# Landing Page Prompts

## Direct-response landing page

Use for city, state, dealer, advertiser, and collection-intake pages.

```text
Write this landing page as direct-response copy inspired by Agora-style structure: curiosity-driven headline, clear problem, reader stakes, specific benefits, proof points, objection handling, and one clear CTA.

Constraints:
- Do not copy any company's exact voice or claims.
- No fake testimonials, guarantees, or made-up statistics.
- Keep it trustworthy for a public coin show directory.
- Include sections for: headline, subheadline, problem, solution, how it works, proof/source notes, FAQ, and CTA.
- Flag any claim that needs verification before publishing.

Page goal: [GOAL]
Target visitor: [VISITOR]
Offer/CTA: [CTA]
Facts/sources to use: [FACTS]
```

## Local SEO landing page

```text
Create a local SEO landing page for [CITY/STATE] coin shows.

Requirements:
- Use only the provided show data and source notes.
- Mention date accuracy limits and tell readers to verify with organizers before traveling.
- Include helpful local intent sections: upcoming shows, nearby cities, what to bring, selling coins, dealer tips, and FAQ.
- Avoid keyword stuffing.
- End with a clear CTA to browse shows or submit a correction.

Provided data: [DATA]
```
