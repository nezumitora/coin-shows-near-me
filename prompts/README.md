# Prompt Library

Reusable prompts for Coin Shows Near Me work.

Rules:

- Keep prompts specific enough to reuse.
- Add prompts only after they produce useful results in real work.
- Do not include private names, credentials, customer data, or unpublished business details.
- Prefer prompts that require accuracy checks, source links, and human review before publishing.

When a new prompt works well, add it to the closest file here and note what it is good for.
