# Directory Expert Follow-up Questions

## Questions pending external guidance

1. Is an organizer reply sufficient for `Organizer verified` when it comes from an email address or social account independently matched to the organizer's official website?
2. If a show has no official website, can an official club or association page, venue calendar, or confirmed venue representative support a separate `Official source verified` or `Venue confirmed` label?
3. Should organizer verification expire after a fixed period, or simply when the verified event date passes?
4. For a credible recurring show awaiting its next date, should it appear in a separate `Recurring — next date pending` section while its permanent page remains indexed?
5. When no future date is confirmed, should Event structured data be removed completely until a new date is verified? For useful one-time historical pages, would you keep them indexed, use `noindex`, or eventually return 404/410?
6. Which free or founding-dealer benefit would you test first: show-attendance listings, enhanced profiles, featured placement, or qualified seller inquiries?

## Current working rule

Organizer, official-source, and venue verification remain distinct. Dealer and community reports can trigger manual research but do not create verified status by themselves. Anyone may submit a correction for review; only independently checked evidence changes the public status.

## Already-recorded guidance

Unrelated expired pages should not redirect to the homepage. Keep one stable indexed URL for a credible recurring series, remove passed dates from upcoming sections, retain useful date history, redirect only to an exact replacement, and use a genuine 404/410 for a thin one-time page with no useful history or successor.
